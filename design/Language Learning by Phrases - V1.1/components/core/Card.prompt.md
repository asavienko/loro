The container for anything grouped inside a screen. 1px hairline, never a shadow.

```jsx
<Card>
  <div style={{ fontSize: 14, fontWeight: 700 }}>Muy bien, gracias.</div>
</Card>
<Card tone="grow">Nothing to fix — this reads naturally.</Card>
```

Use `tone="note"` for explanation ("Why it's said this way"), `tone="dark"` only for one hero card per screen.
